Machine explorer

One machine's year of 2015: a sensor's daily average, with every error code, part replacement and failure marked above it.

How to read this

  • The line is the daily average of the chosen sensor (readings are hourly). Each part has one signature sensor: comp1 → voltage, comp2 → rotation, comp3 → pressure, comp4 → vibration. That sensor shifts in the ~48 hours before the part fails.
  • Hover over a marker for its time and its error code or part. Failures and replacements are logged in a daily 06:00 batch; every failure comes with a replacement of the same part at the same moment.
  • Drag to zoom into a few days; double-click to zoom back out.
