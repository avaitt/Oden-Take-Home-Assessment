Rule explorer: what if we changed the rules?

The write-up chose one warning window: an alarm counts if it comes 48 to 12 hours before a breakdown. Change it here, or focus on one part, and see how the three kept rules score on the 50 test machines they never saw.

Try 1"No time to act": the score barely moves, so keeping 12 hours free costs nothing.
Try 2"Two days to act": C09 collapses. Its error code arrives one day out, so it can't warn earlier than that.
Try 3Switch "Which breakdowns?" to a single part. C09 stays on top for every part.

C09 · Matched signature: a part's own sensor is clearly off its normal and that same part's error code was logged in the last 24 hours.
C08 · Drift + any error: any sensor is clearly off and any error code was logged in the last 48 hours.
C10 · Drift on an aging part: a part's own sensor is clearly off and that part is overdue for replacement. No error code needed, so earlier but noisier.
  • Score (F1) folds "caught" and "real" into one number from 0 to 1; it is high only when both are (write-up, section 5.1). The bracket is the range you'd expect from a different draw of 50 test machines. Lift is how many times more often the rule fires before a breakdown than in normal running.
  • The rules themselves never change as you move the controls; only the scoring window does. For a single part, C09 and C10 watch only that part's own sensor, error code and age. Exact definitions: appendix A.2.
